# Security Policy

## Supported versions

Only the latest release receives security fixes.

## Reporting a vulnerability

Please **do not open a public issue**. Report it privately through
[GitHub private vulnerability reporting](https://github.com/Exe64/mtg-collector/security/advisories/new)
with steps to reproduce and the affected version.

You should get a first answer within a week. Once a fix is released, the
advisory is published and credits the reporter unless asked otherwise.

## Scope

In scope: the backend API, the frontend, the Docker images and the scripts in
`deploy/`. Out of scope: vulnerabilities in your own reverse proxy, host or
third-party services (Scryfall, EDHREC, Commander Spellbook).
